# Amrutha Multi Cuisine Family Restaurant

Responsive React + Vite restaurant website.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Before showing the restaurant owner

Replace the demo menu, prices, food photos, and review text with information verified from the restaurant.

The site is lightweight and static, so a 50-person traffic load is trivial for normal static hosting. For a real launch, deploy the built `dist` folder on Netlify, Vercel, Cloudflare Pages, or similar hosting.
